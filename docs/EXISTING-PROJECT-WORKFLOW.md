# Existing project workflow

Existing projects start in `existing-strict`. Approve the functional Screen Contract, resolve and approve Style, import licensed fonts and exact component assets, bind every required control, then generate component-aware layout slots. An approved layout produces an Underlay Contract and grayscale spatial guide. Image generation produces underlay only. Independent Critique must pass (or carry a reasoned waiver) before deterministic component/text composition. Final approval requires a passing Fidelity Report. `existing-guided` is an explicit user choice and never claims exact fidelity.
