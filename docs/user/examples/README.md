# 新手练习素材

## quick-start-wireframe.png

一张竖屏手游「侠客阵容编成」页面的 UE 线框稿（2160 × 3840 PNG），供《使用说明书》（`docs/user/quick-start-guide.html`）的「10 分钟练习」使用。

### 推荐用法

- **项目类型**：新项目（练习走探索路线最短路径，无需准备字体与组件资产）。
- **建议项目名称**：`快速上手示例`。
- **建议设计意图**（可直接粘贴到「设计意图」输入框）：

  > 设计一个角色编队页面，玩家可以查看成员、调整上阵顺序并确认阵容。

- **练习目标**：不为出好图，只为把「00 输入 → 01 功能解读 → 02 布局 → 03 风格 → 04 视觉探索 → 导出 PNG」完整走一遍，理解每个阶段的批准动作与按钮置灰的含义。
